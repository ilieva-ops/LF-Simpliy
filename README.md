# LF-Simplify Website

A responsive website for **LF-Simplify**, designed to provide information about our services and allow customers to easily get in touch. This project is currently under active development.

## About

The goal of this website is to create a simple, modern, and user-friendly online presence for LF-Simplify. Visitors can learn about our services and contact us through the website.

## Features

- Responsive design
- Modern and clean user interface
- Contact section for customer inquiries
- Service overview
- Mobile-friendly layout
- Ongoing improvements and updates

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Status

This project is currently **under development**. New features, design improvements, and additional pages are being added regularly.

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/ilieva-ops/LF-Simplify.git
```

2. Open the project folder.

3. Open `index.html` in your preferred web browser.

No additional installation is required.
